类型构成与文化变迁

全量 9,579 条按标题前缀分类：求助帖 3,288 / 无标记 2,783 / 分享帖 2,176 / 开源 1,083 / 公告官方 191 / 技术报告 23。三个时代清晰可辨：2015–2017 分享帖文化（转发资料攒金币）→ 2018–2021 求助帖时代（参赛队激增、新人涌入，2019 年求助帖 720 条达峰）→ 2022–2023 开源文化成型（开源成为第一大类，2023 年 182 条）。今天新论坛的「赛后开源季」传统，源头在老论坛最后两年。

深读发现的档案生态事实

  1. 老链接的存活率远高于直觉。论坛自建 OSS 附件抽验存活率约 95%（2015 年的 80MB 附件仍可整包下载）；百度网盘死链率仅约 15%——「老帖=死链」是错误直觉，逐条实测后 2015–2021 年的多数资料今天仍可下载。
  2. 百度网盘对脚本一律谎报「链接不存在」。通过构造假链接做对照实验，发现真假链接返回不同页面模板，据此建立了可靠判活方法（errno/标题启发式）——凡标 dead_link 的均经过实测验证。
  3. HTTP 200 不等于活。Google Code 返回 200 但 body 是边缘节点报错桩；微信文章 200 但内容是反爬页。所有存活判定都验了 body 不只看状态码。
  4. 「指针压缩包」是 2015–2016 的时代特征。大量帖子的「附件」是几百字节的 zip，解开只有一个写着百度网盘链接+提取码的 txt——回复可见+金币经济塑造的分发形态。
  5. 官方 OSS 也非均匀持久。UESTC 2016 冠军队开源的 5 个自建附件全部 404，同域名其他年份文件却完好——档案损失是随机的，不是整体性的。
  6. 官方 2023 Livox 哨兵开源包仍活且巨大。article/9269（建图定位文档+实地扫描原始数据+Lio-Livox/FastLIO+导航仿真）的官方 CDN 直链实测返回 6.2GB 完整包——此前调研标注「仅搜索标题确认」，现已实证存活。
